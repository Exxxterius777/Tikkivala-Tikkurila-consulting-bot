# 🎨 Чат-бот-консультант Tikkurila

[![Python](https://img.shields.io/badge/Python-3.11+-blue.svg)](https://www.python.org/)
[![Flask](https://img.shields.io/badge/Flask-3.0+-green.svg)](https://flask.palletsprojects.com/)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Веб-чат-бот на Flask, который консультирует по российскому ассортименту продукции **Tikkivala (Tikkurila)** (краски, эмали, лаки, грунты, антисептики) и помогает подобрать материал под конкретную задачу.

Проект создан как портфолио аналитика данных: демонстрирует навыки работы с Python, структурирования предметной области, построения логики подбора по правилам и интеграции с внешними API.

---

## ✨ Возможности

### 🎯 Подбор ассортимента
- База из **52 позиций** продукции Tikkurila с атрибутами: категория, блеск, база, площадь, разбавитель.
- Подбор по **ключевым словам** запроса (поверхность, материал, условия эксплуатации).
- Ранжирование по двум критериям: **релевантность** (число совпавших признаков) и **приоритет продажи** (I–IV).
- Комплиментарные товары (грунты, шпатлёвки, растворители) — предлагаются для «новой покраски».
- Запрос «что-то ещё» / «дешевле» — постраничная выдача следующих вариантов.

### 🧠 Консультации по покраске
8 веток с уточняющими вопросами и пошаговыми инструкциями:
- Сложные поверхности (кафель, стекло, пластик)
- Металл и оцинковка
- Терраса / напольная часть снаружи
- Деревянный фасад
- Стены и потолки внутри (включая ванную)
- Дерево внутри (стены, пол, мебель, декор, мелкие изделия)
- Бани и сауны

### 💬 FAQ
17+ типовых вопросов: ЛКМ, базы A/C, колеровка, хранение, инструменты, работа с маслом, разбавление и т.д.

### 📐 Калькулятор площади
Пошаговый ввод габаритов и расчёт окрашиваемой площади:
- Внутреннее помещение: `2 × (длина + ширина) × высота − проёмы`
- Фасад здания: сумма по стенам минус окна и двери
- Отдельная стена

### 🗺️ Поиск магазинов
Интеграция с **Яндекс.Картами**:
- Ссылка на поиск магазинов Tikkurila в указанном городе.
- Опционально — **встроенный виджет** интерактивной карты (через API Геокодера).
- Автоматическое извлечение города из запроса («где купить краску в Новосибирске»).

### 🎨 Интерфейс
- Цвета по брендбуку: сообщения бота — `#DCDCDC`, пользователя — `#F08080`.
- Задержка ответа 1,5 сек — имитация «обдумывания».
- Состояние диалога хранится в `localStorage` — не зависит от cookie и переживает перезапуск сервера.
